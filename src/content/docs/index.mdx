## What you will be able to do

- Look at a clean AI-built result and name how it could still be wrong.
- Ask for the evidence that would confirm or overturn it.
- Explain why raw, clean and derived data stay apart, and what that makes recoverable.
- Decide where a check belongs, and what should happen when it fails.
- Tell a false merge from a real one, and unknown data from a true zero.
- Say where a language model can sit in a pipeline, and where it must not.

## The journey

Each module opens one part of what Kick did, answers one question about your
table, and raises the next. At the end you go back to Kick and decide whether to
publish.

<CourseJourney />

## Who it is for

Anyone who uses AI to work with data and wants to know when to trust the result,
including upper-level or graduate students in data science, statistics or
computer science. No knowledge of soccer is needed. One rule is enough: a match
has two teams and a score, and a season is a set of matches.

The course uses Touchline, a working data platform that collects results from
about a thousand college soccer websites. Riley, Kick and the data you work with are
invented. The other stories in the lessons happened on that platform. Each module also has an
optional lab if you want to run the code. [How to use this guide](./start/how-to-use/)
has the details. Instructors will find capstone projects, pacing and an answer
key under [Teaching](./teaching/instructor-notes/).
