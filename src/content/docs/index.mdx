Touchline is a working data platform for college soccer. It collects what about
a thousand school athletics websites publish, turns it into one consistent
dataset, and publishes it as a public website and a verified analytical
database.

This course uses it as a case study. You will not need to write much code. You
will learn what each part of a data platform is for, how the parts depend on
each other, and which questions expose a result that only looks right. Every
technique here is in production, and each one exists because something went
wrong without it.

<PipelineDiagram />

## What you will be able to do

- Look at a clean AI-built result and name how it could still be wrong.
- Ask for the evidence that would confirm or overturn it.
- Explain why raw, clean and derived data stay apart, and what that makes recoverable.
- Decide where a check belongs, and what should happen when it fails.
- Tell a false merge from a real one, and unknown data from a true zero.
- Say where a language model can sit in a pipeline, and where it must not.

## The journey

The course follows one question: an AI tool hands you a clean result, so how do
you know it is right? Each module answers one part of that question and raises
the next.

## Who it is for

Anyone who works with data and wants to understand how a reliable pipeline is
put together, especially upper-level or graduate students in data science,
statistics or computer science. It helps to know what a table and a join are.
No knowledge of soccer is needed. One rule is enough: a match has two teams and
a score, and a season is a set of matches.

The stories in the lessons happened on the real platform, and the data you work
with is invented. Each module also has an optional lab if you want to run the
code. [How to use this guide](./start/how-to-use/) has the details. Instructors
will find capstone projects, pacing and an answer key under
[Teaching](./teaching/instructor-notes/).
