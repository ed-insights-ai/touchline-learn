## Who it is for

Anyone who uses AI to work with data and wants to know when to trust the result,
including upper-level or graduate students in data science, statistics or
computer science. The only soccer you need is one rule: a match has two teams
and a score, and a season is a set of matches.

Riley, Kick and the data you work with are invented. The other stories in the
lessons happened on the real Touchline platform. Each
module is sized for one sitting, and each has an optional lab if you want to run
the code. [How to use this guide](./start/how-to-use/) has the details.
Instructors will find capstone projects, pacing and an answer key under
[Teaching](./teaching/instructor-notes/).

## The journey

Each module opens one part of the pipeline, answers one question about Riley's
table, and raises the next. At the end you go back to Kick and decide whether to
publish.
