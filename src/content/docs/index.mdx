Touchline is a working data platform for college soccer. It collects what about
a thousand school athletics websites publish, turns it into one consistent
dataset, and publishes it as a public website and a verified analytical
database. A separate app, Touchline Desk, uses that database for AI-enhanced
analysis.

This site uses it as a case study for teaching data engineering to data science
students. Every technique here is in production, and each one exists because
something went wrong without it.

<PipelineDiagram />

## What you will be able to do

- Explain why a pipeline keeps raw, clean and derived data apart, and what each layer is allowed to depend on.
- Design a provenance check for a scraped source, and say what should happen when the check fails.
- Resolve entity names without fuzzy matching, and argue when that is the right choice.
- Tell the kinds of missing data apart, and represent each one in a schema.
- Write a data contract, and build a gate that enforces it.
- Explain what determinism buys, and where a language model can and cannot sit in a pipeline.
- Reason about access, secrets and cost in a system that mixes public code with private data.

## Who it is for

Upper-level undergraduates or first-year graduate students in data science,
statistics or computer science. You should know basic Python or SQL, what JSON
and HTML are, and what a join is. No knowledge of soccer is needed. One rule is
enough: a match has two teams and a score, and a season is a set of matches.

Instructors will find capstone projects, pacing and an answer key under
[Teaching](./teaching/instructor-notes/).
